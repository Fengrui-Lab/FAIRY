# 大豆病害选药来源

两个实际商品：Albaugh TebuStar 3.6L（tebuconazole）与 Bayer Proline 480 SC（prothioconazole）。均参考美国大豆成熟籽粒说明中的亚洲大豆锈病用途，均允许预防或初见症状时喷施。厂商原始PDF和SHA256在catalog.json，运行初始化核验SHA256。

TebuStar说明书第13页：3–4 US fl oz/acre、最少10天、PHI21天、最多3次/年及12 US fl oz/acre/年。Proline 2019说明书第16页：该锈病条目2.5–3.0 US fl oz/acre、最少10天、PHI21天、最多3次/年及12.9 US fl oz/acre/年；不混用另一3–5剂量条目的用途。1US fl oz/acre=73.077783...mL/ha。服务提供100L/ha配药水（高于10gpa）和TebuStar需要的表面活性剂。两药同为FRAC3，换商品不是换作用机制。

DEMO供应报价、承包服务费用、单次病害压力事件及统一通用药效为声明的模拟假设，不是市售价格调查或真实两药药效对比。通用病害压力不等于已确诊锈病，工具也不复刻完整登记制度。Priaxor预防用药原型因与病后选药题意不符被否决，记录保留在validation_runs/management_remaining_20261103/fungicide_preventive_product_probe/。

厂商TebuStar总则建议避免连续超过3次本品或其他FRAC3杀菌剂。本目录保留为最多连续3次同FRAC组的限制；更换为Proline不能重置计数。该约束不虚构抗性发展或药效系数。
