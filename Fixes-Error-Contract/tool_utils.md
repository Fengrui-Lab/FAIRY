# tool_utils.py 错误与校验审阅

源文件：[fairy/tool_utils.py](../fairy/tool_utils.py)

共享工具标记和调用支撑文件，无业务 @app_tool 方法。AppTool.__call__ 直接调用方法；app_tool 只设置标记；此处没有自动包装业务错误。

类型①：已有错误提示不清晰或不准确。类型②：缺少应在执行前完成的校验。P1：可能破坏状态；P2：影响行为或纠错；P3：提示可读性。

## 1. 【类型② / P2】工具 schema 未落实为执行入口校验

- 位置：[55-56, 65-84, 174-182](../fairy/tool_utils.py#L55)。
- 现状/触发：AppTool.__call__ 不校验类型或值；schema 的 type/required 只提供给模型。不能将其当作后端验证，因此原始 JSON 中的坏值能进入方法。
- 建议：集中校验可放在 AppTool 或 type_check/Agent 边界择一实现，必须覆盖没有 @type_check 的工具；避免多层重复校验或更改当前 {"error":"…"} 外形。

## 验收重点

对上述触发输入确认返回非空字符串 `error`；拒绝发生在扣减资源、修改作物或推进时间之前。提示改动应与实际阈值一致，并覆盖修正后的合法调用。没有写明“实测”的项目为静态路径审阅结论。
