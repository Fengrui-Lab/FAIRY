# Jev 默认执行指引（2026-11-04）

> 2026-11-04 版本管理更新：下述强化现仅在 `enforced_tool_adaptor=true` 时启用；默认 false 保留本地 manos 兼容基线。见 [ADAPTOR_PROFILES.md](ADAPTOR_PROFILES.md)。本文原测试数对应首次实现。

按用户要求直接合入主工作区，默认启用，不增加 `detail=true` 专属 Jev 版本或新开关。

## 参数含义

`detail` / `detailed_briefing` 仍只选择场景原有的任务描述详略。适配层在每次 Jev 请求的 state 中添加 `jev_execution_guidance`，对详细和简略任务均使用同一组通用规则；原始 `task` 原样保留，因此也不改变任务数字提取或任务派生的参数候选。

规则使用现有 Jev 适配提示的英文风格，面向两种服务后端和不同任务语言，不翻译或改写场景正文。源文本集中在 `fairy/agents/jev/execution_guidance.py`。

## 默认规则

1. 遵守任务范围。多阶段或全季任务持续至全部要求完成；单次成功不等于全季完成，短任务也不凭空扩展为全季管理。
2. 根据模拟时间、公开观测及真实工具回执判断进度；失败、请求意图或部分覆盖不算全部成功，农场、地块和设备分别核对。
3. 失败后先识别阻塞原因，修正参数或资源条件；相关状态未变时不重复相同失败调用。缺信息时使用相应的可用观测工具。
4. 充电、生长、天气等时间条件阻塞作业时，结合公开完成时间、成熟估计、天气预报或任务日程，考虑选择可用等待工具；不要越过更早的必要管理窗口。等待后复查，单纯时间流逝不算条件已经解除，仍可进行的必要作业继续处理。
5. `done` 对应实际任务要求完成，而不是调用次数或某次成功；工具说明提及状态报告不自动构成最终报告要求。

这些是输入指引，不是自动规划器或新的 Guard。不自动推进时间、不代替模型选择操作、不改变预算，不注入作物日期、施肥量、Oracle 或隐藏状态。原始历史摘要与完成检查的候选补丁继续隔离。

## 作用范围和版本

默认作用于 `farm_jev` 的 Pure-Jev、Hybrid full、REFLEX；snapshot 和 history 输入模式均携带同一指引。Hybrid 回退已有的 state 传递会将它交给回退 LLM。独立的 `farm_llm_jev` 咨询策略和 Pure-LLM 未改。

提示版本为 `jev-execution-guidance-v1`；telemetry 和 `jev_menu` 事件记录版本及 SHA256，实际请求日志保留全文。它改变了模型输入，不能把后续运行当成历史提示完全相同的实验。既有冻结批次、历史结果和队列不改。本次未调用真实模型，也未启动复测；效果尚待实验验证。
