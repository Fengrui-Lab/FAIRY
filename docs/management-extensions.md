# 四个正常地块全季场景与逐步 Oracle

四个场景各自有一个独立 Python 文件，题设、初始资源和全部管理调用均在该文件中逐条写明：

| 场景 | 文件 | 决策 |
| --- | --- | --- |
| B1 | `fairy/scenarios/management_extensions/scenario_multiseason_scn_switch_to_maize.py` | 上季大豆，SCN 18,000枚卵/100cm³，改种非寄主玉米 |
| B2 | `fairy/scenarios/management_extensions/scenario_multiseason_scn_continue_maize.py` | 上季玉米，独立复测仍12,000，继续种玉米 |
| C1 | `fairy/scenarios/management_extensions/scenario_multiobjective_seed_discount.py` | 比较同一品种、质量、种子数量的供应商，选择折扣大豆种子 |
| C2 | `fairy/scenarios/management_extensions/scenario_multiobjective_seed_total_cost.py` | 比较相同玉米种子的含运费总价，选择到货总价较低者 |

每份 `build_events_flow()` 都是字面工具调用及依赖、参数、理由，不包含循环、条件式管理分派、运行时优化器或外部流程文件加载。`common.py` 只装配环境、附加元数据和核算成本，`validation.py` 只验证结果。只有这四个文件通过包的显式目录注册；旧的集中式 `scenarios.py` 不参与运行。

B1、B2的模型输入不再写“换种玉米”或“继续玉米”，只交代已有种植历史，要求读取报告和轮作规则后自行选择。两份独立文件均对称写出玉米、大豆的品种、行数、株距、播深、种子数量、成熟阶段、收获/入库水分及植保支持范围；同时公开两种初始种子的消耗成本。作物尚未选定时不在prompt中放入玉米量级的产量门槛；选择后，`Field.get_crop_capabilities().management_objective`公开原有本场产量及成本验收目标。数值、轮作规则和oracle选择均未改变，错误作物仍可执行、再由验收检查适宜性。本文表格、场景ID和oracle理由属于参考材料，不是任务prompt。

每场共同仓库有800L燃油；机具初始油箱100L，容量100L。沿用原有限制：种箱30万粒、撒肥器500kg、粮箱2,000kg，播种/收割每趟最多4垄，追肥每趟最多10垄。每场写明16趟播种、16趟收获，每收4垄即卸粮一次，各形成一个带来源垄号的批次。正量追肥覆盖64垄需要7趟；加载只装本趟所需产品。收获前及正量追肥前从共同库存补足油箱，按实际转入量扣仓，不重置机具。

共同粮仓容量20,000kg，每日干燥能力20,000kg，和原有玉米场景配置一致；每个批次仍须单独通过实际成熟、天气、通行性、粮箱容量、干燥能力和安全水分检查。产量按真正安全入库后的净质量计算，不使用模型地上生物量或粮箱湿重。

## 重新优化的标准和范围

**本轮最高产量来自正常规模场景重新执行的候选管理集合，旧150m²场景产量和当前参考方案产量都不是基准。**

1. 固定地块、真实天气、品种、土壤与初始状态，对候选方案通过公开工具执行完整种植季。
2. 剔除执行失败的方案，取可行候选的最高安全入库量 `Y_best`。
3. 要求候选安全入库量至少达到 `0.99 × Y_best`，再从中取全季总核算成本最低者；成本同值时取产量较高者。
4. 将实际选中方案的每一步调用、参数、依赖、耗时等待和理由写回四个独立文件。
5. 静态导出后，在独立CLI进程从新初态回放，验证真实结果；再根据回执独立重算成本和候选选择。

玉米对照肥料产品强度0、155⅓、310⅔、466、600kg/ha与水0、60、120、180mm的20个组合；并测试533⅓、566⅔、583⅓、600kg/ha与150、165、175、180mm的未重复组合，共35个。大豆对照肥料0、155⅓、310⅔、600kg/ha与水0、60、90、120、150、180mm，共24个。实际调用以整块田的kg计算，不把每公顷用量直接当全田用量。B1、B2与C2的玉米物理输入相同，复用同一候选范围，但各自独立执行所选方案和历史/采购流程。

肥料非零时固定播前、6月10日各一半；超过500kg的基肥分箱施用。玉米灌溉在7月1/15日、8月1/15日，大豆在7月5/20日、8月5日均分。播种与机具作业真实耗时已计入后续绝对日期的等待秒数，不能直接沿用小地块等待时间。每阶段读取天气、预报、土壤与全部64垄阶段，灌水后隔日复核。收获窗口为大豆9月9日、玉米9月20日，工具仍按真实成熟状态放行。

这里的最佳与最低成本是**上述有限候选范围内的最优**，不是穷尽所有播期、株距、施肥时点和灌溉调度后的全局最优，也不声称田间最佳产量。

## 预算和成本口径

所有价格为公开DEMO假设，不是市场报价。100分=1 DEMO。全季成本包括种子、实际消耗肥料产品50分/kg、实际消耗燃油100分/L、灌水2分/m³、实际干燥粮10分/kg；不含劳动、设备折旧和租地。B类初始持有种子按实际播种消耗量估值：玉米每1,000粒65 DEMO，大豆每6,000粒45 DEMO。装在料斗里尚未播下的种子不会提前计作消耗。

C1相同754,688粒大豆种子：常规7,546.88 DEMO，折扣1,886.72后实付5,660.16，现金余额6,917.97。C2相同85,760粒玉米种子：低标价4,288+运费2,572.80=6,860.80；包邮批次5,574.40，现金余额3,001.60。供应商质量和交货时间相同，立即交付；每个报价只有一个不可拆分批次。采购扣款和仓库增种原子发生，重复订单幂等。

采购现金账户只实际扣种子款；同一个初始限额还约束全季投入核算总额。工具分别显示采购现金余额和扣除全部核算成本后的剩余额度，不能将两者相加或重复扣种子。燃油、肥料和B类种子虽初始持有，也按真实消耗计价；全季总成本超过预算不能通过验证。
