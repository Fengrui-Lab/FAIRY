# 候选去重与实施次序

以下是规格决策，不是模型响应结论。十份规格卡全部保留，正式名额目前为0（均未E1/E2验收）。不要求十种不同生理机制，但必须有不同决策/信息/资源要求。

|候选|处置|新增决策与合法替代|准入或暂缓依据|
|---|---|---|---|
|W01|首先试点|公开低水分下补灌或不补灌|先证明当前环境中合法水处理可传到终产；不是预报或精细诊断标签|
|N01|首先试点|共同预算内全季N60或N120|两剂量均正数基施、均无人工灌溉；不借零基肥拒绝造效应|
|S01|随后筛选|首次可行播种窗或预先固定后一个合法窗|比较完整季物候/成熟与TWSO；需排除工具拒绝伪差异|
|W02|随后筛选|相同实际接受毛水总额的不同安排|先确认两组时点均合法；日期/次数/观测一起变时仅归因完整策略|
|S02|合并入S01|当前只是同一播期问题的另一叙述|没有已实现、公开且独立的准备延迟/期限选择，不单占名额|
|W04|W01环境变体|土层内分别比较阈值与替代|40/100cm同时改变初始水与容量；未证明需适配阈值的独立选择|
|W05|暂缓，先信息门禁|有/无forecast时同一控制器是否改变灌溉|需核实工具真实可见范围和内容；不得从W02差异宣称预报价值|
|N02|暂缓，先可观察性|公开供氮信息是否改变N选择|播前native not_started不能诊断；公共资料或后移时点未落实|
|N03|机制诊断，不单占名额|水×N的响应是否存在可利用取舍|2×2交互≠新决策；若始终多投最好，不能称联合规划能力|
|W03|低优先级暂缓|当前动作和次日可恢复暂缓|旧0.111%不等于当前数值，但提示弱标签；不反复拉长延误直到造出大损失|

## 不可用的“凑数”方式

只换天气年、根深、日期、名称不增加独立任务；W01/W04、S01/S02应共享家族划分。不同信息条件可以形成任务，但须真的通过App菜单/公开内容实现，不是仅在说明里要求策略装作看不到。所有被用于调整策略/阈值的历史环境仍为开发资料。

## 农艺合理性与证据边界

目前只主张水、氮、季节积温在当前模型中的合理候选通路；N60/120是预设实验处理，不是当地农艺推荐；具体生产场景还需记录适用条件和可追溯农艺来源。无需先复原整个历史外部定量校准，也不能把历史模型内结果写成E3。

本次设计没有新增已被排除的病虫草、渍涝恢复、收后动态损耗或多田竞争。若试点无响应/不合法/不闭环，先归因再决定修订、合并或暂停，不自动补满十项。
