# 首轮结果判定与停止规则

## 先验冻结与四条清单

具体机器可读清单见pilot_pair_plan.yaml。W01使用当前water_limit开发家族（2026合成天气、seed101、降雨因子0.25、初始available/base soilN=50/50）；两处理N均120kgN/ha、共同360kg产品库存/配额和150mm毛水额度。N01用nitrogen_limit家族（相同天气生成方法但降雨因子1、初始soilN=5/15），两处理N60/120，人工灌水均0mm、同360kg库存/配额。

两开发环境均保存初始化的4天播前干燥窗与day130起35天后期干燥窗；它们是合成环境条件而非Agent可读未来日程。当前固定0.4m土层、水力参数、品种、WOFOST参数和损失系数不变。

四条不共享参考，因为环境不同。N01选择相同实际0人工水是为隔离N剂量，不保证此环境不受其他水分限制；如N效应弱如实报告，不能偷偷加“每组同阈值”的不同灌水并称纯N效应。

## 顺序判定

1. **身份/接口门禁**：本轮环境哈希、初态、天气、seed/噪声、品种/参数、面积、工具菜单与最终Agent文本都一致；不复用旧6.0.7checkpoint。不符时先判不可比较，不修剪轨迹造通过。
2. **E1**：公开动作合法接受，产品/水台账与native apply_n/irrigation同日结算对应，无重复；拒绝0、部分/未知单列。原生初始池和回收量独立可追踪。
3. **闭环**：两个处理都从未播种到真实成熟与安全收储，守恒和资源不过限。未闭环记录原因，不把仓库0称作生理减产。
4. **E2**：报告成熟TWSO、回收DM和14%标准实际入库的绝对差、相对差（零分母则相对差缺失）。差值保持符号，无截断；观察是否沿预期native输入通路传递。同初态不是模拟日/天气相同的充分条件，必须核对实际forcing。
5. **能力标签**：即使产量有差，也只支持对应处理的模型内收益/响应；不外推诊断、复查、预测、最优规划或现实田间效应。

## 无赢家与弱响应

- 不设“至少5%才算代码正确”，不要求预定策略胜出。完整原生0、同产、负差都保留。
- 数值差异先与单位换算/守恒残差和输出精度比较；不足可靠区分时标`indistinguishable_at_recorded_precision`。不以事后挑选阈值把微差写成强能力。
- 单开发环境的一条配对不能声称统计显著或跨年稳定。小差值完整披露，是否足以成为正式任务按其决策/容错尺度评审；若采用数值准入界限，必须下轮运行前另行冻结，不在看结果后追认。
- 无响应先分：动作未生效（执行问题）、输入实际不同/同量不成立（公平问题）、环境不限制、模型弱响应、设计没有形成不同选择。保留负结果，不自动扩展80条矩阵或换天气直到胜出。
- 需要修订则新设计版本/新运行ID并记录原因，原结果不覆盖；查看过的环境为开发。W03不因PCSE变化优先重做。
