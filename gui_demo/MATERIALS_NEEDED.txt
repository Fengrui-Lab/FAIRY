This list is fillable. Nothing below is claimed to have been captured by FAIRY.
Leave URL and source fields empty when material is unavailable. A working demo
can use the exported numeric records without any of these external assets.

ALREADY AVAILABLE — DO NOT FABRICATE OR RE-ENTER
- 374 executed tool events and 375 global frames, including the initial state.
- Soil/canopy observations, numeric NDVI and canopy temperature, ground
  detection confidence/coverage, crop stages, actions, inventory and devices.
- Per-ridge simulation truth is separate from Agent-observed tool results.
- Neither drone nor ground-inspection output contains an RGB photograph,
  thermal raster, bounding box, segmentation mask or raw spectral image.
- Disease pressure is a model index, not a diseased-leaf percentage.
- Residual protection days are not a measured pesticide-residue concentration.

HOW TO FILL THE CATALOG
Edit assets/catalog.json. Set url to a relative local asset path or a permitted
external URL; set source_type (for example actual_photo, measured_data,
demo_illustration, model_asset or geometry_data), caption and acquired_at.
Use ISO 8601 with timezone for a real acquisition time, or null when unknown.
Keep original event tool names/results unchanged. Source descriptions and
usage permissions belong to the supplied material, not to the simulation.

All from_step/to_step bounds below are INCLUSIVE event/frame indices.
Frame 0 is the initial state; frame N is the state after event N.
Never display an event-support image before its from_step. Before-treatment
images expire before the first intervention. Static crop/equipment references
are marked reference-only and must never masquerade as a live observation.
When adding real material from a later date, advance from_step accordingly.

RIDGE MAPPING
Both farm plots visibly use raw ZERO-BASED ridge IDs 0-63.
The target interval is 20-39 inclusive (20 ridges); it is not 20% of a field.
Ground disease checks sample 28-31 and 32-35 (eight ridges), not all 20.
Do not relabel raw ridge 0 as ridge 1 or silently switch to one-based indexing.
Backend soybean_field = farm plot A; maize_field = farm plot B.
